## 3. 分级标准

| 级别 | 定义 | 处置 |
|---|---|---|
| A | 高价值必读：官方文档、体系化深度长文（原理/源码/集群/分片/最佳实践） | 人工确认后转写为知识库笔记 |
| B | 有价值深读：具体技术主题的优质文章 | 按主题分组，作为延伸阅读导航 |
| C | 参考速查：安装、配置、单点技巧、排错 | 保留速查，不转写 |
| D | 低价值：错放、近似重复、缓存/死链平台、论坛问答、聚合站 | 人工确认后从浏览器删除 |

## 4. 分级流水线

三个脚本（`scripts/`），可对任意方向复用：

```bash
# 1. 结构画像：顶层/方向分布
python3 scripts/analyze_structure.py source/bookmarks.html

# 2. 方向分级：抽取 方向/<名称>，去重后 A/B/C/D 分级，输出 data/<方向>.json
python3 scripts/bookmark_scale.py SQL

# 3. 渲染清单：生成 guide/<方向>.mdx（概览 + A 转写清单 + B/C 主题导航 + D 清理建议）
python3 scripts/render_scale.py SQL
```

分级规则（`bookmark_scale.py`，机器首轮、规则可迭代）：

- **D 信号**：错放关键词（按方向配置）、低价值平台（百度快照/文库、CSDN 论坛、新浪博客、IT 屋、docs4dev 镜像等）、同归一化标题重复、同文件夹对比类超 2 篇；
- **A 信号**：官方文档域名白名单（无操作类关键词干扰）、标题深度信号（原理/源码/体系/集群/分片/最佳实践/3W字等）；产品首页一律降 B；URL 带广告投放跟踪参数（bd_vid/utm_source=baidu 等）的厂商营销落地页不进 A/B；
- **C 信号**：安装/部署/配置/报错/速查类关键词；
- **兜底**：具体子分类下 → C，无主题散链 → D。
