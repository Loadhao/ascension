# example：订单管理接口文档

> **EXAMPLE**：内容虚构，仅演示接口文档应包含什么，不代表当前项目。新增真实接口文档时参考本文件结构，使用业务语义命名，勿覆盖本文件。

## 概述

订单管理入口提供订单创建与分页查询能力。

- 接口前缀：`/manage/order`
- 认证方式：Bearer Token

## 创建订单

`POST /manage/order/create`

根据商品标识和数量创建待支付订单。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| skuId | Long | 是 | 商品标识 |
| quantity | Integer | 是 | 购买数量，最小为 1 |
| remark | String | 否 | 备注，最长 200 字 |

### 请求示例

```json
{
  "skuId": 10001,
  "quantity": 2,
  "remark": "尽快发货"
}
```

### 响应参数

| 字段 | 类型 | 说明 |
|---|---|---|
| orderId | Long | 订单标识 |
| status | String | 订单状态 |

### 响应示例

```json
{
  "orderId": 9001001,
  "status": "PENDING_PAY"
}
```

### 错误与边界

| 条件 | 结果 |
|---|---|
| 未认证 | 返回认证失败 |
| quantity 小于 1 | 返回参数错误 |
| 商品不存在 | 返回资源不存在 |

## 分页查询订单

`POST /manage/order/pageQuery`

请求至少说明分页字段、筛选条件和排序规则；响应说明总数、列表项结构与时间格式，并给出完整 JSON 示例。
