多线程并发

首页/Java/高级/多线程并发

从线程模型到 JUC 框架的完整进阶路径，按学习顺序排列——前四个知识点是理解 AQS 与线程池的前置。点击右侧圆点标记状态。

  • 01 线程生命周期与状态转换 核心 NEW / RUNNABLE / BLOCKED / WAITING / TIMED_WAITING / TERMINATED 六态流转与触发条件
  • 02 synchronized 与监视器锁 核心 对象头 Mark Word、锁升级（偏向 → 轻量 → 重量）、字节码语义
  • 03 volatile 与内存可见性 核心 JMM 主内存/工作内存、happens-before、内存屏障与伪共享
  • 04 CAS 与原子类 Unsafe.compareAndSwap、ABA 问题、LongAdder 对比 AtomicLong
  • 05 AQS 源码解析 核心 state + CLH 队列、独占/共享模式、Condition 队列，读 ReentrantLock 与 Semaphore
  • 06 线程池与执行框架 ThreadPoolExecutor 七参数、执行流程、拒绝策略、Runnable vs Callable
