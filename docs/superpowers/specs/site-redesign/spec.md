# 全站重设计：黑白主题 + 进阶信息架构 · 设计规格

## 1. 界面等级与目标视口

- 界面等级：**L3**（全站多状态：双主题 × 多页面 × 交互标记 × 响应式）
- 目标视口：桌面 ≥960px（侧边栏布局）、移动 375–430px（抽屉导航）、打印（自动浅色）
- 现状证据：
  - 首页 = 5 方向卡片列表（不驱动学习）；侧边栏仅 方向→笔记 两级
  - 全站为 Starlight 默认主题（冷蓝灰深色/纯白浅色），用户反馈「丑」；暖调 v1 方案被否（亮要纯白、暗要纯黑）
  - 用户核心诉求：以 基础/中级/高级 进阶触发学习；层级要划分类别（如 Java 高级下分 JVM、多线程并发、内存池）
  - 真实笔记仅 2 篇；纯静态站（无后端）；无用户系统

## 2. 功能点与非目标

| 编号 | 功能点 |
|---|---|
| F1 | 双轴五级信息架构：内容轴 = 方向 → 等级（基础/中级/高级）→ **分类（目录页）** → 知识点（笔记），同级可有子分类嵌套；进阶轴 = 等级作为导航与呈现层（每方向独立定级） |
| F2 | 黑白主题：亮 = 纯白底 `#FFFFFF` + 近黑文字；暗 = 纯黑底 `#000000` + 近白文字；**默认深色**，手动切换后 localStorage 记住 |
| F3 | 灰阶无彩色系统：链接 = 文字色 + 下划线（悬停加深）；学习状态用图形区分（空心圆 ○ 未学 / 半圆 ◐ 学习中 / 实心圆 ● 已掌握），不依赖颜色 |
| F4 | 字重调轻：正文 400 / H2–H4 500 / H1 600 |
| F5 | 首页 = 学习仪表盘：① 继续上次学习（大卡：笔记名 + 进度 + 继续按钮）② 各方向进度（等级位置 + 百分比）③ 下一步推荐（衔接逻辑）|
| F6 | 方向首页 = 等级分段路线图：基础/中级/高级三段，段内分类为**可点击目录入口**（进入分类页），段头带完成计数 |
| F6a | **分类目录页**：分类（如「多线程并发」）本身是一个页面——面包屑（方向/等级/分类）+ 分类简介 + 该主题下知识点全列表（每条：知识点名 + 一句话简述 + 核心标记 + 状态圆点），列表为学习顺序 |
| F7 | 学习状态标记：路线图/分类页条目与笔记页底部两处入口，点击圆点循环 未学→学习中→已掌握，localStorage 持久化 |
| F8 | 侧边栏五级树：方向 → 等级 → 分类（可点击，进入分类页）→ 知识点；当前路径高亮，分类节点与知识点节点视觉可区分（分类带目录图标） |

**非目标**：跨设备同步进度（纯静态站）、复习提醒机制、知识图谱改版（节点数据加 level 字段自动兼容）、搜索改版、Mermaid 图表内部配色、多用户。

## 3. 布局与响应式规则

- 桌面 ≥960px：顶栏（logo + 搜索 + 主题切换）+ 左侧边栏（四级树）+ 内容区。侧边栏宽 240px。
- <960px：侧边栏收为抽屉（☰），内容单列全宽。
- 仪表盘三块纵向排布（继续学习 → 方向进度 → 下一步推荐），紧凑间距。
- 打印：自动浅色、隐藏侧边栏与交互控件。

## 4. 信息层级与设计令牌

- 灰阶令牌（对应 Starlight `--sl-*` 变量）：

| 令牌 | 浅色（纯白） | 深色（纯黑） | 用途 |
|---|---|---|---|
| `--sl-color-black`（页面底） | `#ffffff` | `#000000` | 页面背景 |
| `--sl-color-white`（主文字） | `#111111` | `#f5f5f5` | 标题主文字 |
| `--sl-color-gray-2`（正文） | `#333333` | `#d4d4d4` | 正文 |
| `--sl-color-gray-3`（辅助） | `#767676` | `#8c8c8c` | 侧边栏 inactive/辅助 |
| `--sl-color-gray-5`（边框） | `#e5e5e5` | `#262626` | 边框/分隔线 |
| `--sl-color-gray-6`（次级表面） | `#f7f7f7` | `#0d0d0d` | 代码底/卡片底 |
| `--sl-color-gray-7`（导航表面） | `#fafafa` | `#0a0a0a` | 顶栏/侧边栏底 |
| `--sl-color-accent`（链接） | `#111111` | `#f5f5f5` | 链接 = 文字色 |
| `--sl-color-accent-high` | `#000000` | `#ffffff` | 悬停加深 |

- 等级标记（灰阶）：基础 = ◇ / 中级 = ◈ / 高级 = ★（细线 SVG 图形，尺寸 12px）
- 状态圆点（12px SVG）：未学 = 空心圆；学习中 = 半填充圆；已掌握 = 实心圆
- 字重：H1 600、H2–H4 500、正文 400；系统字体栈不变
- 对比度：深色正文 `#d4d4d4`/`#000` ≈ 14.9:1、辅助 `#8c8c8c` ≈ 7.4:1；浅色正文 `#333` ≈ 12.6:1、辅助 `#767676` ≈ 4.5:1，全部达标

## 5. 交互、反馈与动效

- 链接：文字色 + 下划线（下划线透明度 40%），悬停加深至纯黑/纯白 + 下划线实色，150ms
- 状态圆点：点击循环三态，动画 120ms（圆点填充过渡）；半圆用 SVG 半径遮罩实现
- 焦点：`:focus-visible` 双线环（外浅内深灰阶），不依赖悬停
- 主题切换：默认深色；点按钮切换并将偏好写入 localStorage；打印强制浅色
- 尊重 `prefers-reduced-motion`：去除过渡仅保留状态突变

## 6. 无障碍约束

- 状态不只靠颜色：圆点图形本身即语义（空心/半/实心），并配 `aria-label`（"标记为已掌握"）
- 焦点环 2px 双线，键盘 Tab 顺序 = 视觉顺序
- 触控目标：状态圆点热区 ≥32×32px（含 padding）
- 等级分段头带 `aria-labelledby`；路线图条目为链接，语义化 `<a>`

## 7. 实现约束

- 内容迁移：`src/content/docs/<方向>/<等级>/<分类>/`（如 `java/advanced/concurrency/`）；分类目录含 `index.mdx`（分类页）+ 各知识点 `.md`；frontmatter 增 `level`（basic/intermediate/advanced）与 `status`（planned/learning/mastered，作者视角）
- 侧边栏：Starlight sidebar 手动嵌套 group 映射四级；`astro.config.mjs` 同步更新
- 仪表盘/路线图/状态标记：React 岛屿（`Dashboard.tsx`、`Roadmap.tsx`、`ProgressMark.tsx`），构建期从内容集合聚合统计，运行时读 localStorage 合并读者进度
- 主题：`src/styles/custom.css` 覆盖 `--sl-*` 为上表灰阶；Shiki 代码主题换 `github-light` / `github-dark`
- 图谱 JSON 节点增 `level` 字段（可选），组件兼容缺省
- 不将 Widget 内联样式整段拷入生产，只迁移令牌与结构
