# 方向入口卡片 · 设计规格

> **EXAMPLE**：内容虚构，演示 L2 设计资产的 `spec.md` 写法，不代表待实现需求。真实功能的设计规格随 `<design-root>/<feature-id>/spec.md` 落盘，勿覆盖本文件。

## 1. 界面等级与目标视口

- 界面等级：**L2**（新区域 + 布局变更）
- 目标视口：移动端 375–430px（单列）、桌面 ≥960px（三列网格）、打印（A4 纵向单列）
- 现状证据：首页方向入口由 [src/content/docs/index.mdx](../../../src/content/docs/index.mdx) 的 Starlight `CardGrid`/`Card` 组件渲染，样式完全由主题默认值决定，无进度提示、无未开放方向的占位表达。

## 2. 功能点与非目标

| 编号 | 功能点 |
|---|---|
| F1 | 首页按方向展示入口卡片网格（Linux / Java / Python / AI / 工具） |
| F2 | 卡片悬停与键盘焦点反馈（抬升 + 描边） |
| F3 | 卡片键盘可达：Tab 顺序即视觉顺序，Enter 进入方向首页 |
| F4 | 未开放方向以禁用卡片占位（如「数据库 · 即将上线」），不可聚焦 |
| F5 | 方向学习进度提示（笔记数 + 学习中标记） |

**非目标**：卡片拖拽排序、跨方向聚合视图、后端进度统计接口（本例为静态内容站，进度来自构建期文件计数）。

## 3. 布局与响应式规则

- 桌面 ≥960px：三列网格，列间距 16px，卡片等高。
- 640–959px：两列网格。
- <640px：单列，卡片全宽，间距 12px。
- 打印：单列，去除阴影与交互反馈。

## 4. 信息层级与设计令牌

- 层级：方向名（H3，18px/600）> 简介一行（14px，次要色）> 进度徽章（12px）。
- 令牌沿用 Starlight `--sl-*` 体系思路，本 Widget 演示用暖调低饱和变量：

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#f8f7f4` | `#1c1a17` | 页面背景 |
| `--surface` | `#ffffff` | `#262320` | 卡片面 |
| `--text` | `#2d2a26` | `#e8e4dc` | 主文字 |
| `--text-muted` | `#7a736a` | `#9a928a` | 次要文字 |
| `--accent` | `#b45309` | `#d9a066` | 强调/进行中 |

- 圆角 12px；间距节奏 4px 基数；阴影仅一层（`0 1px 3px rgba(60,50,40,.08)`）。
- 文案来源：方向简介复用各方向 `index.mdx` 首段描述，不另行编写。

## 5. 交互、反馈与动效

- 悬停：卡片 `translateY(-2px)` + 描边转强调色，150ms ease-out。
- 焦点：`:focus-visible` 双线描边（外浅内深），不依赖悬停样式。
- 禁用：不响应指针，光标 `not-allowed`，整体 60% 透明度。
- 动效遵循 `prefers-reduced-motion: reduce` 时去除位移，仅保留描边变色。

## 6. 无障碍约束

- 卡片为 `<a>`，整卡可点；禁用卡 `aria-disabled="true"` 且 `tabindex="-1"`。
- 文字对比度：主文字 ≥7:1，次要文字 ≥4.5:1（本令牌在浅/深两主题下均满足）。
- 焦点目标尺寸：卡片高度 ≥96px，满足触控目标。

## 7. 实现约束

- 生产实现复用 Starlight `CardGrid`/`Card` 或等价 Astro 组件 + `custom.css` 令牌，不引入新依赖。
- Widget 中的内联样式仅用于评审，不得整段拷贝进生产代码。
- 禁用卡片数据来自构建期脚本对方向目录的探测（本例虚构「数据库」演示形态）。
