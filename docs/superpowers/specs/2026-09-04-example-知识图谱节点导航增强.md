## 背景与目标

知识图谱当前仅支持点击节点跳转笔记，无法预览关联内容。本规格为图谱节点增加悬浮预览与高亮邻接能力，提升浏览大图谱时的定位效率。

## 范围

- **包含**：节点悬浮卡片（标题 + 摘要 + 标签）、邻接边高亮、图谱数据结构扩展
- **不包含**：跨方向图谱联动、节点编辑（仍由 JSON 数据文件维护）

## 交互规则

| 状态 | 说明 | 退出条件 |
|---|---|---|
| hover | 悬浮节点 300ms 后展示预览卡片 | 移出节点或点击 |
| focus | 点击节点（无 href）后高亮该节点与邻接边，其余淡化 | 点击空白处或 Esc |
| active | 点击带 href 节点直接跳转笔记 | — |

- 预览卡片宽 280px，移动端改为底部抽屉
- 高亮邻接时非相关节点透明度降至 0.15

## 数据模型

### `src/data/graphs/<方向>.json` 扩展字段

| 字段 | 类型 | 说明 |
|---|---|---|
| summary | String | 节点摘要，预览卡片展示，最长 120 字 |
| tags | String[] | 标签列表，预览卡片展示 |

已有字段（`id`、`label`、`href`、`group`、`source`、`target`）语义不变，新字段均可选，保证旧数据兼容。

## 组件接口

| 组件 | 变更 | 说明 |
|---|---|---|
| KnowledgeGraph.tsx | 新增 props `enablePreview?: boolean` | 默认 true，控制悬浮卡片开关 |

内部新增 `NodePreviewCard` 子组件，仅由 KnowledgeGraph 引用，不单独导出。

## 风险与未决项

| 项 | 说明 | 处理建议 |
|---|---|---|
| 移动端 hover 语义 | 触屏无 hover，悬浮卡片不可达 | 移动端改为长按触发，一期先做底部抽屉 |
| 大图谱性能 | 节点数超过 200 时淡化动画掉帧 | 用 `cy.batch()` 合并样式更新，必要时降级为直接切换透明度 |
