# 全站暖调主题重做 · 设计规格

## 1. 界面等级与目标视口

- 界面等级：**L2**（全站视觉变更：配色、字重、代码块、各表面）

- 目标视口：桌面 ≥960px（侧边栏布局）、移动 375–430px（抽屉导航）、打印（自动浅色）

- 现状证据：

  - [src/styles/custom.css](../../../src/styles/custom.css) 仅有图谱容器样式，全站视觉为 Starlight 默认主题

  - 默认深色为冷蓝灰（slate 底 + 蓝紫灰阶 + 蓝色强调），与用户「沉稳暗暖调、低饱和」偏好相悖

  - 默认标题字重偏重（600–800），观感生硬

## 2. 功能点与非目标

| 编号 | 功能点                                    |
| -- | -------------------------------------- |
| F1 | 深色主题改为暖褐黑夜：暖黑底 + 暖白文字 + 柔琥珀强调，灰阶整体去蓝转暖 |
| F2 | 浅色主题改为米白纸感：奶油底 + 暖墨文字，边框/分隔线暖化         |
| F3 | 字重整体调轻：正文 400、二级及以下标题 500、一级标题 600     |
| F4 | 代码块与行内代码表面暖化（深色：暖炭底；浅色：米灰底），语法色采用低饱和暖调 |
| F5 | 链接与交互反馈：琥珀强调色、悬停加深/上浮、焦点环双线暖色          |
| F6 | 侧边栏/顶栏与正文形成柔和层次（同色相不同明度，不引入新色相）        |

**非目标**：布局结构变更（侧边栏/内容区位置不动）、新增组件、加载外部字体（继续系统字体栈）、Mermaid 图表内部配色（构建时 SVG，后续单独议题）。

## 3. 布局与响应式规则

布局不动，仅换肤。断点沿用 Starlight 默认（960px 侧边栏显隐）。打印沿用现有 print.css 行为（自动浅色）。

## 4. 信息层级与设计令牌

层级不变：H1 > H2 > 正文 > 辅助文字。令牌映射到 Starlight `--sl-*` 变量体系：

- 字重：`h1 { font-weight: 600 }`、`h2–h4 { font-weight: 500 }`、正文 400。

- 字体栈：系统栈不变（不加载网络字体，保持轻量）。

- 圆角：沿用 Starlight 默认（8–12px），不额外加大。

- 代码语法色（Shiki 双主题，深色为例）：注释 `#7f7767`、关键字 `#c98a5e`、字符串 `#a3b37e`、函数 `#d9b48a`、变量 `#c9c1b6`；浅色对应提亮（注释 `#9a9186`、关键字 `#a15c20`、字符串 `#5d7a2e`、函数 `#8a5a28`）。

## 5. 交互、反馈与动效

- 链接悬停：强调色加深（accent → accent-high），150ms ease-out，无位移。

- 焦点：`:focus-visible` 双线焦点环（外浅内深琥珀），2px/2px。

- 主题切换沿用 Starlight 内置开关，无新动效。

- 尊重 `prefers-reduced-motion`（本项目仅颜色过渡，天然满足）。

## 6. 无障碍约束

- 正文对比度：深色 `#c9c1b6`/`#171412` ≈ 10.5:1；浅色 `#55504a`/`#faf8f5` ≈ 7:1 ✓

- 辅助文字：深色 `#a49a8d` ≈ 6.5:1；浅色 `#6f665c` ≈ 4.8:1 ✓

- 链接：深色 `#d9a066` ≈ 8:1；浅色 `#b45309` ≈ 5.1:1 ✓

- 非颜色通道：链接保留下划线（悬停显现），焦点环不依赖悬停。

## 7. 实现约束

- 全部通过 `src/styles/custom.css` 覆盖 `--sl-*` 变量实现，零新依赖、零布局改动。

- 代码语法色通过 Astro 配置切换 Shiki 双主题（浅 `vitesse-light` 思路 / 深 `vitesse-dark` 思路），实现时验证 Astro 7 的 shikiConfig 与现有 `excludeLangs` 配置兼容。

- 图谱组件（KnowledgeGraph）节点配色已为暖调，与新主题天然兼容，不改。

- 不将 Widget 内联样式整段拷入生产，只迁移令牌值。
