## 交互式知识图谱

各方向首页的力导图由 `src/data/graphs/<方向>.json` 驱动，格式：

```json
{
  "nodes": [
    { "id": "jvm", "label": "JVM 内存", "href": "/java/jvm/memory/", "group": "JVM" }
  ],
  "edges": [
    { "source": "jvm", "target": "gc", "label": "依赖" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `id` | 节点唯一标识，边通过它引用 |
| `label` | 节点显示文本 |
| `href` | 可选；填写后节点带金色描边、点击跳转到对应笔记 |
| `group` | 可选；分组决定节点颜色，同组同色 |
| `source` / `target` | 边的两端节点 `id` |
| `label`（边） | 可选；边上的关系说明 |

维护流程：新增笔记后，在对应方向的 JSON 里加一个节点，`href` 填笔记路径，
再补上与已有知识点的关联边即可。
