## 学习路线

按等级推进，每级下按主题分类。点击分类进入该主题的知识点目录；点击圆点标记学习状态：
○ 未学 → ◐ 学习中 → ● 已掌握。

当前覆盖**消息队列**主线：为什么需要 MQ 与三大选型（基础）→ Kafka
架构/ISR/可靠性（中级）→ 顺序性与高性能、RocketMQ 特性、积压治理
（高级）。后续可扩展 Elasticsearch、ZooKeeper 等分类。
