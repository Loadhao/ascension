## 学习路线

按等级推进，每级下按主题分类。点击分类进入该主题的知识点目录；点击圆点标记学习状态：
○ 未学 → ◐ 学习中 → ● 已掌握。

本方向收录**跨工具横向内容**：为什么需要消息队列（解耦/异步/削峰与代价）
和三大主流 MQ 选型（Kafka / RocketMQ / RabbitMQ）。各具体中间件的深入
笔记见独立的 **Kafka** 与 **RocketMQ** 方向。后续可扩展 ZooKeeper / etcd
等横向综述。
