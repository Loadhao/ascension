## 学习路线

按等级推进，每级下按主题分类。点击分类进入该主题的知识点目录；点击圆点标记学习状态：
○ 未学 → ◐ 学习中 → ● 已掌握。

当前覆盖 **基础核心**（倒排索引、分词与映射、文档/分片）→ **查询聚合**
（Query DSL、全文与精确查询、聚合分析），后续可扩展集群架构、写入/查询优化、
Logstash/Kibana 生态与日志场景等主题。
