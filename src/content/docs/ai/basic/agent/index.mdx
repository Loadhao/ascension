## 从 30 行循环到生产级 Harness

Learn Claude Code 的 20 课揭示了一个核心事实：**最小的可用 Agent 就是一个
while 循环**——调用模型、执行工具、回传结果。生产级系统（如 Claude Code）
的 1729 行 query.ts 核心仍是这 30 行，其余都是叠加在其上的保护机制。
