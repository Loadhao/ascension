基础循环跑起来之后，决定 Agent 上限的是五件事：

- **怎么想**——任务规划（先列清单再动手）与系统提示组装（prompt 是拼出来的）
- **看什么**——上下文工程与记忆系统（压缩有损，要有不丢的一层）
- **懂什么**——RAG 检索增强与技能按需加载（知识注入的两条路线）
- **稳不稳**——错误恢复（错误是重试的起点，不是终点）
- **连什么**——MCP 协议（像 USB-C 一样接上外部世界）

## 七个机制在循环中的位置

```mermaid
flowchart TD
    A[用户输入] --> SP[系统提示组装<br/>按真实状态拼 section]
    SP --> L[调用 LLM]
    L --> T{tool_use?}
    T -- 是 --> PT[权限闸门<br/>allow / ask / deny]
    PT --> EX[执行工具<br/>钩子前后注入行为]
    EX --> L
    T -- 否 --> ST[错误恢复<br/>分类失败再重试]
    ST --> R[最终回答]
    M[记忆系统<br/>跨会话存活] -.注入.-> SP
    K[技能加载<br/>用到才花 token] -.tool_result.-> L
    P[任务规划<br/>对抗注意力稀释] -.reminder.-> L
```
