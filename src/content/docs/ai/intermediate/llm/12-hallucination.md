LLM 用流畅自信的语气说出完全虚构的文献、API、历史事件——**幻觉**
（hallucination）是 LLM 应用的第一质量敌人，也是面试必考题。正确答案
的第一句是：**幻觉不能被消灭，只能被系统性管理**——它的根源在模型的
工作原理里。

## 三层根源：不是 bug，是机制的副产品

1. **训练目标只奖励"像"不奖励"真"**：下一 token 预测的损失函数衡量
   "与训练语料的分布像不像"——**流畅且自信的回答天然得分高**，哪怕
   事实是编的；SFT 语料里几乎全是"有标准答案的问答"，模型没学过
   "承认不知道"；
2. **知识边界**：训练截止日期后的知识、私域知识模型根本没有——但
   补全模式会让它"编一个像样的"而不是拒答；
3. **采样随机性**：temperature>0 时每次生成路径不同，幻觉时有时无
   ——但 **temperature=0 也有幻觉**（贪心解码照错不误），说明随机性
   只是放大器不是根源。

## 治理矩阵：按层布防

| 层 | 手段 | 能压住什么 |
| --- | --- | --- |
| 数据层 | SFT 加入"拒答/承认不知道"样本 | 让模型学会说不知道 |
| 架构层 | **RAG 接地**：检索资料+强制引用出处 | 私域/时效知识的幻觉（最大头） |
| 推理层 | 低温、要求"逐条给依据"、思维链 | 降低概率，不根除 |
| 系统层 | **评测集测幻觉率**、关键场景人工审核、输出 disclaimer | 兜底与度量 |

- **RAG 是主力但不是解药**：检索不到/检索错时模型仍会脑补；"有出处"
  的回答也可能是错误引用——RAG 把幻觉率从"高"压到"低"，压不到零
  （RAG 进阶篇的检索质量问题会转化为幻觉）；
- **引用核对**：让模型标注"这段话来自检索片段第 N 条"，系统层抽查
  引用与原文的一致性——可验证的接地。

## 检测：幻觉率是可度量的

- **自一致性**：同一问题多次采样（高温度），答案互相矛盾 → 大概率
  幻觉；
- **评测集幻觉率**：黄金问答集里模型输出与标准答案的事实一致性
  （LLM-as-judge 打分或人工抽检）——应用评估篇的指标之一；
- **线上信号**：用户点踩、追问"你确定吗"的比例。

## 高频追问速答

- **温度调到 0 能消除幻觉吗？** 不能——幻觉根源是训练目标与知识边界，
  采样只是放大器；低温让输出稳定，但稳定地错。
- **RAG 能消除幻觉吗？** 压低不消除：检索不到会幻觉、检索错了会错上
  加错、生成端仍可能无视资料——所以知识库篇强调"引用核对+未找到就
  明说"。
- **为什么模型不承认不知道？** SFT 数据几乎全是"有答案"的对——模型
  被训练成"永远给出回答"；治理要从数据层补"拒答样本"。

## 小结

- 幻觉根源三层：训练目标奖励"像"、知识边界触发补全、采样放大——
  **机制性存在，只能管理不能消灭**。
- 治理矩阵按层布防：RAG 接地是主力、拒答样本教模型说不知道、评测集
  度量幻觉率、关键场景人工兜底。
- 面试标准句式："幻觉的管理是概率工程——RAG 降概率、引用可验证、
  评测有度量、关键场景有兜底。"
