## 学习路线

按等级推进，每级下按主题分类。点击分类进入该主题的知识点目录；点击圆点标记学习状态：
○ 未学 → ◐ 学习中 → ● 已掌握。

当前覆盖 **MySQL**（执行流程 → 索引 → 事务/锁/日志 → 优化 → 复制与分片）与
**Redis**（数据结构 → 持久化 → 淘汰与缓存问题 → 高可用），后续可扩展
MongoDB / Elasticsearch 等分类。
