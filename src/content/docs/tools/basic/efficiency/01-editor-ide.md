## 为什么编辑器是效率第一杠杆

写代码的大部分时间不在打字，而在**改、跳、查**。把高频操作练成肌肉记忆，
比任何技巧都划算。主流现代编辑器（VS Code 及 Vim/Neovim 系列）都提供了
一套"动作组合"，核心思想相通。

## 核心操作清单

| 操作 | VS Code | 通用价值 |
|---|---|---|
| 快速打开文件 | `Ctrl/Cmd+P` | 免去找文件的手动导航 |
| 命令面板 | `Ctrl/Cmd+Shift+P` | 一切命令的入口 |
| 多光标 | `Cmd+D` 选中同类 / `Alt+Click` | 批量改同名变量 |
| 跳转定义 | `F12` / `Cmd+Click` | 顺藤摸瓜读代码 |
| 全局搜索 | `Ctrl/Cmd+Shift+F` | 跨文件找符号/字符串 |
| 整行移动/复制 | `Alt+↑↓` / `Shift+Alt+↓` | 快速调整代码位置 |

**核心思想**：减少鼠标、减少上下滚动、任何重复动作都想办法"一键化"。

## 多光标：最值得练的一个技巧

当你要把 5 处相同的 `var` 都改成 `let`，或给多行同时加引号，多光标是效率
倍增器：

```text
1. Cmd+D 逐个选中下个相同词（跳过用 Cmd+K Cmd+D）
2. 直接输入替换内容
3. 或 Alt+Click 在任意位置点出多个光标
4. 配合 Alt+↑↓ 给多行同时编辑
```

## 代码片段（Snippet）

把重复的样板代码存成"输入缩写 → 自动展开"：

```json
{
  "log": {
    "prefix": "clog",
    "body": ["console.log('$1', $1);"],
    "description": "console.log with variable"
  }
}
```

输入 `clog` 回车即展开，光标停到 `$1` 处。**凡是写过三次以上同样的样板，
就该考虑固化成 snippet。**

## 常用扩展思路

按需安装，别贪多：

| 类别 | 例子 | 价值 |
|---|---|---|
| 语言支持 | 对应 LSP 扩展 | 补全、跳转、报错 |
| 格式化/检查 | Prettier、ESLint | 统一风格、提前纠错 |
| Git | GitLens 等 | 溯源、diff、blame |
| 主题/字体 | 等宽字体 + 连字 | 可读性 |

## 小结

- 高频动作（开文件、跳转、多光标、搜索）练成肌肉记忆。
- 多光标是批量编辑的核心技能；snippet 是消除重复码的首选。
- 扩展按需装，别让它拖慢启动与心智负担。
