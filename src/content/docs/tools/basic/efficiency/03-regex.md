## 正则是什么

正则（Regex）是用模式字符串匹配文本的通用语言，跨语言跨工具通用。它出现在
grep/sed/awk、编辑器搜索、各类编程语言、日志清洗等一切"找文本"的场景里。

## 核心语法

| 语法 | 含义 | 例子 |
|---|---|---|
| `.` | 任意单字符 | `a.b` 匹配 `aab`/`axb` |
| `\d` | 数字 | `\d+` 一串数字 |
| `\w` | 单词字符（字母数字下划线） | `\w+` |
| `\s` | 空白 | `\s` 空格/换行 |
| `[abc]` | 字符类（任一） | `[aeiou]` 元音 |
| `[^abc]` | 取反 | `[^0-9]` 非数字 |
| `^` `$` | 行首 / 行尾 | `^Error` 行首 Error |

## 量词

| 量词 | 含义 |
|---|---|
| `*` | 0 次及以上 |
| `+` | 1 次及以上 |
| `?` | 0 或 1 次 |
| `{n}` | 恰好 n 次 |
| `{n,}` | 至少 n 次 |
| `{n,m}` | n 到 m 次 |

## 分组与捕获

```text
(log|warn|error)     # 分组：匹配三选一
(\d{4})-(\d{2})      # 捕获组：后续可 \1 \2 引用
(?:...)              # 非捕获分组
```

## 贪婪 vs 非贪婪

这是正则最容易踩的坑：

```text
<.*>     贪婪：匹配 "<a>b</a>" 中最长的 "<a>b</a>"（吃最多）
<.*?>    非贪婪：匹配最短的 "<a>" 和 "</a>"（吃最少）
```

**默认贪婪，加 `?` 变非贪婪**。解析 HTML/引号内容时几乎总要用非贪婪。

## 常见场景速写

| 场景 | 正则 |
|---|---|
| 匹配邮箱 | `[\w.+-]+@[\w-]+\.[\w.]+` |
| 匹配 IP | `\d{1,3}(\.\d{1,3}){3}` |
| 匹配日期 | `\d{4}-\d{2}-\d{2}` |
| 提取引号内容 | `"([^"]*)"` |

## 小结

- 三块核心：字符类（`[]` `\d`）、量词（`*+?{n}`）、分组（`()`）。
- 记住贪婪/非贪婪：默认吃最多，`?` 变吃最少。
- 工具里 `grep`/编辑器/语言都通用，写前先想"要匹配什么、边界在哪"。
