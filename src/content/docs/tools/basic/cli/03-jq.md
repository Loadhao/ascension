日志和接口返回常是一大坨 JSON，肉眼难读。jq 把这坨东西变成**可按字段
提取、过滤、重组**的结构化数据。

## 基本用法

```bash
curl -s https://api.example.com/users | jq .            # 排版美化
curl -s ... | jq '.name'                                # 取字段
curl -s ... | jq '.[0].name'                            # 取数组第 0 项字段
curl -s ... | jq '.data[].name'                         # 遍历 data 数组取 name
```

- 裸 `.` 是"当前对象"，`.[]` 遍历数组，`字段` 直接取。
- 结果同样带引号；想要纯原始值加 `-r`（raw）。

## 过滤与重组（高频）

```bash
jq '.[] | select(.score > 80) | .name'           # 条件筛选再取字段
jq '.data | map({name, id})'                     # map 重组为新的对象数组
jq '.total = 100'                                # 新增/覆盖字段
jq '{items: .data[]}'                            # 改造成新结构
jq 'length'                                      # 数组长度
jq -r '.[].name'                                 # 输出不带引号，方便接脚本
```

管道里第一个 `|` 后的 `select`、`map` 配合字段是核心组合。

## 组合实战

```bash
# 找出所有错误码是 500 的项目名
curl -s https://api.example.com/deploys | jq -r '
  .[] | select(.status == 500) | .project'

# 统计计数
curl -s https://api.example.com/events | jq '[.[] | .type] | group_by(.)[]
  | "\(.[0]): \(length)"'
```

## 把 jq 想成"过滤器流"（深入）

jq 的难点在它的心智模型不是"改字符串"，而是**把 JSON 变成连续的"值流"，
再用过滤器逐个变换**。两个最反直觉的点搞懂就过关：

1. **`.data[]` 会"展开成多个值"**：它让 `data` 数组的每个元素**各自输出一行**
   而不是一个数组。所以：

   ```bash
   echo '[1,2,3]' | jq '.[]'         # 输出三行：1\n2\n3（不是 [1,2,3]）
   echo '[1,2,3]' | jq '.'            # 输出一行：[1,2,3]
   ```

   想要"对每个元素处理后大爷都保留"就记住 `[]` = "展开成流"，没有 `[]` =
   "整个数组当作一个值"。**管道流用错 `[]` 是最常见的输出"不对"之源**。

   用一张图理解"展开成流" vs "整体当一个值"：

   ```mermaid
   flowchart LR
       subgraph whole["没有方括号：整体当一个值"]
           A["[1,2,3]<br/>（一整块）"] -->|"输出一行"| A1["[1,2,3]"]
       end
       subgraph opened["有方括号：展开成流"]
           A0["[1,2,3]"] -.->|展开| B["1"]
           A0 -.->|展开| B2["2"]
           A0 -.->|展开| B3["3"]
           B --> B1["1（一行）"]
           B2 --> B2a["2（一行）"]
           B3 --> B3a["3（一行）"]
       end
       style opened fill:#eef3ea
   ```

   所以 `.[] | select(...)` = "把每个元素分别过一遍过滤器"。

2. **`-r`（raw）值得随时记**：默认 jq 输出仍带 JSON 引号，`-r` 剥掉转义，
   得到纯文本，方便接 Next 脚本/循环。

```bash
# -r 接 read 循环，处理每一行
curl -s ... | jq -r '.data[].name' | while read n; do echo "处理 $n"; done
```

**常见失效快查**：

| 现象 | 原因 |
|---|---|
| 输出还是带引号/含 `\n` | 没加 `-r` |
| `select` 之后结果"变少" | `select` 对**每个展开的元素**判断，忘了先 `.[]` |
| 取数组第一个元素写成 `.data.name` | 应该是 `.data[0].name` 或 `.data | .[0]` |
| 嵌套太深报 `Cannot iterate` | 目标不是数组却用了 `[]` |
| 大文件卡死/内存高 | 忘了它是全量流式加载；超大 JSON 用 `jq --stream` 或切片 |

## 小结

- jq = **字段提取 + select 过滤 + map 重组**，输出自动排版。
- 需要纯文本接脚本时记得 `-r`。
- 与 curl 最搭：`curl -s URL | jq '...'` 一次完成请求 + 解析。
