日志和接口返回常是一大坨 JSON，肉眼难读。jq 把这坨东西变成**可按字段
提取、过滤、重组**的结构化数据。

## 基本用法

```bash
curl -s https://api.example.com/users | jq .            # 排版美化
curl -s ... | jq '.name'                                # 取字段
curl -s ... | jq '.[0].name'                            # 取数组第 0 项字段
curl -s ... | jq '.data[].name'                         # 遍历 data 数组取 name
```

- 裸 `.` 是"当前对象"，`.[]` 遍历数组，`字段` 直接取。
- 结果同样带引号；想要纯原始值加 `-r`（raw）。

## 过滤与重组（高频）

```bash
jq '.[] | select(.score > 80) | .name'           # 条件筛选再取字段
jq '.data | map({name, id})'                     # map 重组为新的对象数组
jq '.total = 100'                                # 新增/覆盖字段
jq '{items: .data[]}'                            # 改造成新结构
jq 'length'                                      # 数组长度
jq -r '.[].name'                                 # 输出不带引号，方便接脚本
```

管道里第一个 `|` 后的 `select`、`map` 配合字段是核心组合。

## 组合实战

```bash
# 找出所有错误码是 500 的项目名
curl -s https://api.example.com/deploys | jq -r '
  .[] | select(.status == 500) | .project'

# 统计计数
curl -s https://api.example.com/events | jq '[.[] | .type] | group_by(.)[]
  | "\(.[0]): \(length)"'
```

## 小结

- jq = **字段提取 + select 过滤 + map 重组**，输出自动排版。
- 需要纯文本接脚本时记得 `-r`。
- 与 curl 最搭：`curl -s URL | jq '...'` 一次完成请求 + 解析。
