图的 BFS / DFS 与树遍历同宗，但有两个图特有的必修项：**visited 集合**（图有环、还有交叉边，
不标记必然死循环或重复爆炸）和**邻接表建图**。两者的输出顺序截然不同——
BFS 按层扩散（最短路的基础），DFS 一条路扎到底（连通性、环检测、拓扑的基础）。

## Java 实现

```java
Map<Integer, List<Integer>> graph = new HashMap<>();  // 邻接表建图
for (int[] e : edges) {
    graph.computeIfAbsent(e[0], k -> new ArrayList<>()).add(e[1]);
    // 无向图：补反向边
    graph.computeIfAbsent(e[1], k -> new ArrayList<>()).add(e[0]);
}

// BFS：队列 + visited 入队时标记（防止重复入队）
public List<Integer> bfs(int start) {
    List<Integer> order = new ArrayList<>();
    Set<Integer> visited = new HashSet<>();
    Queue<Integer> queue = new ArrayDeque<>();
    queue.offer(start);
    visited.add(start);
    while (!queue.isEmpty()) {
        int cur = queue.poll();
        order.add(cur);
        for (int next : graph.getOrDefault(cur, List.of())) {
            if (visited.add(next)) {  // add 返回 false 表示已在集合，跳过
                queue.offer(next);
            }
        }
    }
    return order;
}

// DFS：递归天然用调用栈
public void dfs(int cur, Set<Integer> visited, List<Integer> order) {
    if (!visited.add(cur)) return;  // 已访问：回退
    order.add(cur);
    for (int next : graph.getOrDefault(cur, List.of())) {
        dfs(next, visited, order);
    }
}
```

**visited 标记的时机是两种遍历各自的经典坑**：BFS 必须**入队时**标记（出队时标记会导致同一节点被塞进队列多次）；
DFS 递归版**进入时**标记即可。

## 复杂度与特点

| 维度 | BFS | DFS |
| --- | --- | --- |
| 时间 | O(V + E) | O(V + E) |
| 空间 | O(V) 队列（最宽层） | O(V) 递归栈（最长链） |
| 输出序 | 按距起点的层数递增 | 沿链深入再回溯 |
| 信号词 | 最短步数、层序、扩散 | 连通块、环检测、路径存在性 |

## 面试要点

- **无权最短路 = BFS** 是铁律：「迷宫最少步数」「单词接龙」「转盘锁」全是 BFS；一步带权立刻换 Dijkstra。
- **连通块计数**（LC 200 岛屿数量）：外层扫每个格子，没访问过就发起一次遍历并计数——BFS/DFS 都行，网格图四方向就是邻接表。
- **环检测**：无向图 DFS 遇到「已访问且非父节点」即有环；**有向图**用三色标记（白灰黑，遇灰色即环）——拓扑排序笔记里的环判定是它的应用。
- 手写坑：BFS 忘记入队时标记（队列爆炸）；递归 DFS 对大数据爆栈（改显式栈）；建图漏掉无向边的反向。
