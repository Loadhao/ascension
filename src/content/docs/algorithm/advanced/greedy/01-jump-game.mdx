跳跃游戏是贪心的标杆题，两个版本一条思想线：数组每格是可跳的最大步数。
**版本 I**（LC 55）只问能否到终点——维护一个「最远可达」变量；**版本 II**（LC 45）求最少步数——
把「步数 k 能到达的下标」看成一**层**，逐层推进直到覆盖终点。层的概念就是 BFS 的层，
贪心版的妙处是把队列省成两个区间端点。

## Java 实现

```java
// 版本 I：能否到达——最远可达掉出 i 之前必然扫过 i
public boolean canJump(int[] nums) {
    int farthest = 0;
    for (int i = 0; i < nums.length; i++) {
        if (i > farthest) return false;  // 这个格子永远到不了
        farthest = Math.max(farthest, i + nums[i]);
        if (farthest >= nums.length - 1) return true;
    }
    return true;
}

// 版本 II：最少步数——贪心分层
public int jump(int[] nums) {
    int jumps = 0, layerEnd = 0, farthest = 0;
    for (int i = 0; i < nums.length - 1; i++) {  // 终点格不用再起跳
        farthest = Math.max(farthest, i + nums[i]);
        if (i == layerEnd) {  // 走完当前层：必须再跳一步
            jumps++;
            layerEnd = farthest;
            if (layerEnd >= nums.length - 1) break;
        }
    }
    return jumps;
}
```

**贪心正确性（交换论证）**：任何最优解的第一跳，都可以换成「当前层内可达最远的那个跳法」而不劣化后面——
因为下一层的可达范围只会更大。每层边界 `[上层层尾 + 1, 本层最远]` 内的所有格子都是「同一步数可达」的，
这正是 BFS 的层定义，只是我们只关心层的边界而不需要队列。

## 复杂度与特点

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 时间 | O(n) | 每格只扫一次（版本 II 的双层观感是错觉，i 单调前进） |
| 空间 | O(1) | 三个变量 |
| 对比 DP | dp[i] = 最少步数的解法 O(n²) | 贪心靠「层间无后效性」砍掉一维 |

## 面试要点

- **「贪心分层 ≈ BFS」是本题的点睛话术**：层 = 同步数可达的下标集合，BFS 队列里放的是点，贪心记的是层的两个端点——数据规模大时这种「区间化」是常见优化手段。
- **贪心 vs DP 的判断**：能证明「局部最优不破坏全局最优」就贪心（O(n)），证明不了就老实 DP（O(n²)）。面试先给贪心 + 交换论证，被追问正确性时再展开。
- 变体追问：**带负数步数**（某些格子是陷阱）贪心失效、回退 DP；**删除获得分数**类题也是「区间推进」思想。
- 手写坑：版本 II 的循环上界是 `length - 1`（站在终点不用跳，多算一步）；版本 I 的 `i > farthest` 判断要在更新 farthest **之前**。
