链表题的全部难点都在「指针」：断链、丢节点、死循环是三大经典事故，脑内模拟指针走向又是出了名的反直觉。
这里用三个最高频的模板题把指针套路练透——反转（改指向）、判环（快慢指针）、合并（接线），
每个知识点都配有节点盒 + 调头箭头的动态演示，看着箭头一根根翻转，指针怎么走一目了然。
