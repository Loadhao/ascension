最长公共子序列（LCS，LeetCode 1143）是**二维 DP 的标准样本**：两个字符串互相依赖，
状态必须开成 `dp[i][j]` = s1 前 i 个字符与 s2 前 j 个字符的 LCS 长度。
转移只有两句：字符相等 → 左上角 + 1；不等 → 上、左取较大。它是 diff 工具（git diff）的地基。

## Java 实现

```java
public int longestCommonSubsequence(String s1, String s2) {
    int m = s1.length(), n = s2.length();
    int[][] dp = new int[m + 1][n + 1];  // 多一圈 0 边界，免掉 i/j 越界特判
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;  // 相等：LCS 多一个公共字符
            } else {
                // 不等：丢一个字符取较优
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}
```

**边界圈 0 的技巧**值得专门记：`dp` 多开一圈 0，`dp[0][*]`、`dp[*][0]` 天然为 0——
「空串与任何串的 LCS 是 0」这个语义直接由数组默认值承担，循环从 1 开始、永不越界。

**滚动行压缩**（演示的画法）：`dp[i][*]` 只依赖 `dp[i-1][*]`（上一行）和 `dp[i][j-1]`（本行左侧），
两行即可滚动；再配合一个对角线临时变量可压到单行 O(n)。回溯输出 LCS 本体则需要完整表（从右下角按转移来源往回走）。

## 复杂度与特点

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 时间 | O(mn) | 双层填表 |
| 空间 | O(mn)，滚动 O(n) | 要还原 LCS 本体时不能压 |
| 前提 | 子序列不要求连续 | 连续版本是「最长公共子串」，转移去掉 max 分支即可 |

## 面试要点

- **二维 DP 的叙述模板**（对照一维三题）：状态 dp[i][j] 的含义 → 转移的「最后一步」分类（s1 末字符用/不用 × s2 末字符用/不用）→ 边界圈零 → 填表顺序按行。讲清「为什么不等时取 max(上, 左)」：丢掉哪个末字符都不优于留下的方案。
- 同族题一网打尽：**编辑距离**（LC 72，转移多一个「替换 = 左上 + 1」分支）、**最长公共子串**（不等时置 0 而非取 max）、**两个字符串的删除操作**（LC 583）——全是同一张表的变体。
- 与回溯的分界：LCS 只求长度，DP 最优；要**列出所有** LCS 时回溯（对照回溯分类）。子序列问题「求值用 DP、求所有解用回溯」是通用分界线。
- 工程关联：`git diff` 的最小编辑脚本就是 LCS/编辑距离的行级应用，Myers diff 是其空间优化版。
