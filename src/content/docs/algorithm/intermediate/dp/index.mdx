动态规划入门只需要抓住三件事：**状态定义**（dp[i] 是什么意思）、**转移方程**（dp[i] 从哪些更小的状态推出来）、**边界与顺序**（从哪开始推）。
这里用三个一维经典题把这套流程走熟——爬楼梯是纯递推，打家劫舍引入「选与不选」的决策，
Kadane 展示「负资产果断丢弃」的贪心式转移。每个题都配 DP 表逐格填的动态演示，转移方程看着柱子长出来。
