打家劫舍（LeetCode 198）：沿街一排房子，不能偷相邻两家，求最大收益。
它是「**每一步在选与不选之间做决策**」这类 DP 的母题——买了股票、拿了offer、选了任务，
只要约束是「相邻互斥」，骨架都是同一个转移方程：
**dp[i] = max(不偷第 i 家：dp[i-1]，偷第 i 家：dp[i-2] + nums[i])**。

## Java 实现

```java
public int rob(int[] nums) {
    int prev2 = 0, prev1 = 0;              // dp[i-2]、dp[i-1]，初始为「一家都没偷」
    for (int x : nums) {
        int cur = Math.max(prev1, prev2 + x);   // 不偷 vs 偷
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

**「不偷」也可能优于「偷」**是理解关键：不是见钱就偷——偷了 i 就强制放弃 i-1，
只有 `nums[i] + dp[i-2] > dp[i-1]` 时才划算。演示里第 4 家（金额 9）偷了，
第 5 家（金额 3）就没偷——偷它只能接在 dp[1]=7 上得 10，不如不偷的 11。

## 复杂度与特点

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 时间 | O(n) | 一遍扫描 |
| 空间 | O(1) | 两个滚动变量 |
| 决策结构 | 每步两个分支，但**重叠子问题**极多 | 暴力枚举 2ⁿ 种组合，DP 砍到 O(n) |

## 面试要点

- **变体链是本题真正的考点**（LeetCode 198 → 213 → 337）：**环形版**（首尾相邻）拆成两个线性问题——不偷第一家的 [1..n-1] 与不偷最后一家的 [0..n-2]，取较大者；**树形版**（二叉树上的相邻约束）每个节点返回「偷 / 不偷」两个值自底向上——一维 → 环形 → 树形，状态设计和遍历方式在变，转移思想不变。
- **「选与不选」是最大的一类 DP 家族**：打家劫舍、买卖股票（持有/不持有）、背包（装/不装）全是同一形状——面试说「这题本质是打家劫舍式选与不选」是高质量的解题语言。
- 为什么暴力是 2ⁿ 而 DP 是 O(n)：决策树有大量重叠（dp[i] 被反复重算），自底向上填表让每个状态只算一次——这就是「重叠子问题」的具体形态，和爬楼梯笔记的演进是同一件事。
- 手写坑：滚动变量初值（都为 0 = 空街合法）；两户人家时 `max(nums[0], nums[1])` 要覆盖。
