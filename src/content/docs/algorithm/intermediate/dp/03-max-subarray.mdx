最大子数组和（LeetCode 53，数组含负数，找连续子数组的最大和）的最优解是 **Kadane 算法**：
一遍扫描，`cur` 记录「**以 i 结尾**的最大子数组和」——它要么延长前面的子数组，要么从自己重开，
`cur = max(nums[i], cur + nums[i])`。翻译成人话：**前面的累计是负资产就果断丢弃**。

## Java 实现

```java
public int maxSubArray(int[] nums) {
    int cur = nums[0], best = nums[0];
    for (int i = 1; i < nums.length; i++) {
        cur = Math.max(nums[i], cur + nums[i]);   // 延长 or 重开
        best = Math.max(best, cur);               // 答案是历史峰值，不是末尾值
    }
    return best;
}
```

两个易错点：**best 更新在循环内**（cur 只保证「以 i 结尾」最优，全局最优是所有 cur 的最大值）；
**初始化用 nums[0]** 而不是 0——全负数组 `[-3, -1]` 答案是 -1，初始化 0 会错误返回 0。

**前缀和视角的等价推导**（对照数组技巧笔记）：子数组和 = 前缀差 `P[j] - P[i]`，
最大化它 = 枚举 j 时减去「此前最小的前缀」——维护历史最小前缀，同样是 O(n) 一遍。
两种视角殊途同归，面试能同时说清是理解深度的信号。

## 复杂度与特点

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 时间 | O(n) | 一遍扫描 |
| 空间 | O(1) | cur、best 两个变量 |
| 对比暴力 | 枚举区间 O(n²) + 前缀和预处理仍是 O(n²) | Kadane 靠「负资产丢弃」跳过所有劣质起点 |

## 面试要点

- **「以 i 结尾」是这道题的灵魂状态设计**：普通「前 i 个的最大」无法转移（不知道子数组断没断），加上「结尾」约束后左右子问题无缝衔接——DP 里给状态加维度/约束以恢复无后效性，是标准手法。
- 变体追问链：**返回子数组本身**（记录重开时的起点）；**环形数组**（LC 918，答案 = max(普通 Kadane, 总和 - 最小子数组和)，注意全负的特例）；**乘积最大子数组**（LC 152，负负得正要同时维护最大/最小两个状态——「以 i 结尾」框架不变，状态数翻倍）。
- 与滑动窗口的分界：窗口要求指标单调（如全正数求和），含负数的「最大和」不满足单调性，滑窗失效——Kadane 的「负资产丢弃」正是处理负数的正确姿势。
- 一句话总结给面试官：「每个位置只关心接不接前面的尾巴，负的尾巴不如不接」。
