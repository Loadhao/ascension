爬楼梯（LeetCode 70，每次跨 1 或 2 阶，求 n 阶的走法数）是动态规划的「Hello World」。
它的价值不在难度，而在**演进路径**：暴力递归（O(2ⁿ)）→ 记忆化（O(n)）→ 递推填表（O(n)）→ 滚动变量（O(1) 空间）。
DP 的所有核心概念——重叠子问题、最优子结构、边界、转移方程——都在这 4 行代码里。

## Java 实现

**为什么是 `dp[i] = dp[i-1] + dp[i-2]`**：到达第 i 阶的最后一步只有两种可能——从 i-1 阶跨 1 步，或从 i-2 阶跨 2 步。
两类走法互不重叠又覆盖全部，直接相加。

```java
public int climbStairs(int n) {
    if (n <= 2) return n;
    int prev2 = 1, prev1 = 2;          // 滚动变量：dp[i-2]、dp[i-1]
    for (int i = 3; i <= n; i++) {
        int cur = prev1 + prev2;
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

从暴力递归到这里的完整演进（面试常要求逐层优化）：

```java
// 1. 暴力递归 O(2^n)：f(n) = f(n-1) + f(n-2)，f(3) 被算了两遍、f(2) 三遍……
int climb(int n) { return n <= 2 ? n : climb(n - 1) + climb(n - 2); }

// 2. 记忆化 O(n)：加一个缓存，每个 f(i) 只算一次——「重叠子问题」被消灭
// 3. 递推填表 O(n)：自底向上，就是演示里的 dp 数组
// 4. 滚动变量 O(1) 空间：dp[i] 只依赖前两个，整个数组都可以不留
```

## 复杂度与特点

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 时间 | O(n) | 一遍递推 |
| 空间 | O(1) | 滚动变量；填表版 O(n) |
| 前提 | 无后效性 | 走到 i 阶的方案数只与 i 有关，与路径无关 |

## 面试要点

- **「DP 四步法」用这题示范**：定义状态（dp[i] = 到 i 阶的走法数）→ 转移方程 → 初始化（dp[0]=1, dp[1]=1）→ 遍历顺序（从左到右）。所有 DP 题面试叙述都按这个模板走。
- **dp[0] = 1 而不是 0**：「站在地面」算一种方案（什么都不做），这个边界错了整个数列全错——DP 题最多的 off-by-one 就在边界。
- 变体追问：允许「每次 1/2/3 阶」→ 三项和；「某些阶不能踩」→ dp[i] 置 0 继续；「最小花费爬楼梯」（LC 746）→ dp[i] = min(dp[i-1], dp[i-2]) + cost[i]——同一骨架换转移方程。
- 与斐波那契的关系要说破：这就是斐波那契的「物理意义版」，但 DP 视角比「兔子数列」更有推广价值——状态设计思维从这里起步。
