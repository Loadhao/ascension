二叉搜索树（BST）在树上叠加了一条有序不变量：**每个节点的左子树全部小于它，右子树全部大于它**（对每个节点递归成立）。
这条性质把「在树中找值」变成每层一次二选一——目标小走左、大走右；
也让中序遍历（左根右）的输出恰好**全局升序**。两个演示各讲一面。

## Java 实现

```java
/** 查找：每层二选一，平衡时 O(log n) */
public TreeNode searchBST(TreeNode root, int val) {
    while (root != null && root.val != val) {
        root = val < root.val ? root.left : root.right;
    }
    return root;
}

/** 插入：查找到空位，把新节点挂上去 */
public TreeNode insertIntoBST(TreeNode root, int val) {
    if (root == null) return new TreeNode(val);
    if (val < root.val) root.left = insertIntoBST(root.left, val);
    else                root.right = insertIntoBST(root.right, val);
    return root;
}

/** 验证 BST（LC 98）：不能只比较节点和直接孩子——要用「上下界夹逼」 */
public boolean isValidBST(TreeNode root) {
    return valid(root, Long.MIN_VALUE, Long.MAX_VALUE);
}
private boolean valid(TreeNode node, long lo, long hi) {
    if (node == null) return true;
    if (node.val <= lo || node.val >= hi) return false;   // 越界即非法
    return valid(node.left, lo, node.val) && valid(node.right, node.val, hi);
}
```

**验证为什么不能只看左右孩子**：`5 / \ 1 6` 里 6 的孩子 3 合法，但 3 小于整棵左子树的上界 5——
BST 的约束来自**全部祖先**，所以要把 `(lo, hi)` 开区间一路传下去夹逼。

删除节点分三种情况：叶子直接删；单孩子让孩子顶上；双孩子用**中序后继**（右子树最左节点）顶替再删后继——删除是 BST 手写题的最高频扣分点。

## 复杂度与特点

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 查找 / 插入 / 删除 | 平均 O(log n)，最坏 O(n) | 退化为链（依次插入有序数据）时线性 |
| 中序遍历 | O(n) 输出升序 | 「BST 中序 = 有序数组」 |
| 空间 | O(h) | 与遍历相同 |

## 面试要点

- **最坏 O(n) 的根治是自平衡**：AVL（严格平衡）、红黑树（近似平衡，插入删除常数小）——`TreeMap`/`TreeSet` 就是红黑树，对照 Java 集合笔记里的红黑树篇。
- 与二分查找的对照（呼应二分笔记）：有序数组把有序性存放在「下标」上，BST 存放在「结构」上——前者查 O(log n) 改 O(n)，后者插删都是 O(log n)，这是「查询多改得少用数组+二分，边插边查用平衡树」的选型依据。
- **第 K 小**（LC 230）：中序遍历数到第 K 个即停；**范围查询**：中序 + 剪枝（小于 low 不进左子树）。
- 工程关联：数据库索引的 B+ 树是 BST 的多叉磁盘版（矮胖减少 IO），`ConcurrentSkipListMap` 用跳表解决同样的有序动态集合问题——BST 是这一族结构的思想源头。
