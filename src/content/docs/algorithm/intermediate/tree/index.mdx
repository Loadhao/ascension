二叉树是递归的天然训练场：绝大多数树题都是「遍历框架 + 在正确的时机做事」。
先把四种遍历的差别焊牢——深度优先三种只差「访问根的时机」，层序靠队列分层；
再进二叉搜索树，看有序性如何把查找、验证、第 K 小全部变成一遍遍历的事；
最后用翻转二叉树体会「框架不变、换掉访问动作」的套路。
