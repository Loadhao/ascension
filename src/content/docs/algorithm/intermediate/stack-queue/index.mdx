栈与队列是最简单的两个数据结构，面试考的从来不是它们本身，而是两件事：
**识别「该用栈」的信号**（最近的先配对、嵌套结构、需要回溯），
以及**用栈模拟/组合出别的结构**（最小栈用空间换时间，双栈负负得正拼出队列）。
每个知识点都配有竖直栈列的动态演示，压栈弹栈看得见。
