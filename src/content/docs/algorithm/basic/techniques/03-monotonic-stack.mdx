「对每个元素，找它右边第一个比它大（小）的元素」是很多题的核心子问题。暴力解对每个位置向右扫，O(n²)。
单调栈（Monotonic Stack）的思路：**栈里存下标、让对应的值始终保持单调（这里从底到顶递减）**。
新元素到来时，比它小的栈顶全部弹出——**谁被弹出，谁的「下一个更大」就当场确定为这个新元素**。
每个元素至多入栈一次、出栈一次，整体 O(n)。

## Java 实现

```java
/** 返回每个元素右边第一个更大元素的下标，没有则 -1 */
public static int[] nextGreater(int[] a) {
    int n = a.length;
    int[] ans = new int[n];
    Arrays.fill(ans, -1);
    Deque<Integer> stack = new ArrayDeque<>();      // 存下标，对应值从底到顶递减
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && a[stack.peek()] < a[i]) {
            ans[stack.pop()] = i;                   // 弹出的元素当场拿到答案
        }
        stack.push(i);
    }
    return ans;                                     // 栈里剩下的是右边没有更大的
}
```

方向与单调性的组合共四种，全是同一骨架换比较符：「下一个更大」从左扫、栈递减；「下一个更小」栈递增；
要「左边第一个更大」就从右往左扫。写题时先默写骨架再改方向，比每次重想要快得多。

**为什么是 O(n)**：看起来两层循环，但 `pop` 的总次数不超过 `push` 的总次数（每个下标只进栈一次），
总操作数 ≤ 2n——这是「均摊分析」的标准入门例子。

## 复杂度与特点

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 时间 | **O(n)** | 每个元素入栈、出栈至多各一次（均摊） |
| 空间 | O(n) | 栈；最坏全递减输入时全部留在栈里 |
| 信号词 | 「下一个更大/更小」「最近的」「跨度」 | 题面出现这些词先想单调栈 |

## 面试要点

- **每日温度（LC 739）**：找「几天后升温」= 下一个更大元素的距离 `j - i`，是这道模板最直白的包装。
- **柱状图中最大的矩形（LC 84，Hard）**：以每根柱子为高度的最大矩形，宽度向两侧延伸到「第一个比它矮的柱子」——左边第一个更小用一次单调栈，右边第一个更小再来一次（或一遍同步完成）。接雨水（LC 42）也有单调栈解法。这两道是单调栈的「毕业考」。
- **为什么存下标不存值**：多数题要返回下标或距离（温度题要 `j - i`），值可以随时 `a[idx]` 反查，反过来不行。
- **循环数组变体**（LC 503 下一个更大元素 II）：数组首尾相接，常用技巧是「逻辑翻倍」——遍历 `2n` 次用 `i % n` 取下标，第二轮只弹栈不再入栈。
- 与滑动窗口的分界：滑窗维护「当前连续区间」的指标，单调栈维护「待定元素的等待队列」——一个面向区间、一个面向元素配对。
