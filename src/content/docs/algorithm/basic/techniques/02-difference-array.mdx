前缀和是「数组 → 累加和」；差分（Difference Array）是反过来的「累加和 → 数组」：
`diff[i] = a[i] - a[i-1]`。它的价值在**区间修改**：给区间 `[l, r]` 整体加 v，
朴素做法要改 r - l + 1 个位置，差分只要两个端点——

```text
diff[l] += v    （从 l 开始「抬高」v）
diff[r+1] -= v  （到 r+1 就「落回」）
```

最后对 diff 做一趟前缀和，就还原出目标数组。m 次区间修改的总代价从 O(nm) 降到 **O(n + m)**。

## Java 实现

```java
/** 构造期：只记端点修改，不逐位写 */
int[] diff = new int[n];
void add(int l, int r, int v) {
    diff[l] += v;
    if (r + 1 < n) diff[r + 1] -= v;     // r+1 越界则无需落回
}

/** 结束后一趟还原出目标数组（差分的前缀和 = 原数组） */
int[] a = new int[n];
for (int i = 0; i < n; i++)
    a[i] = (i == 0 ? 0 : a[i - 1]) + diff[i];
```

经典落地场景——**航班预订统计**（LC 1109）：`bookings[i] = [first, last, seats]` 表示该航班段每站加 seats 个座位，
最后输出每站总人数；公交上下车、活动日期区间加成、评分区间打分，全是同一个形状。

## 复杂度与特点

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 单次区间修改 | **O(1)** | 两个端点各改一次 |
| 最终还原 | O(n) | 一趟前缀和 |
| 空间 | O(n) | 差分数组 |
| 适用 | **修改期间不需要查询** | 所有修改攒着，最后一次还原 |
| 失效场景 | 边改边查 | 需要线段树（区间 lazy 标记）或树状数组 |

## 面试要点

- **与前缀和互为逆运算**是理解核心：`(a 的差分) 的前缀和 = a`，`(a 的前缀和) 的差分 = a`——一维场景两者成对出现，面试常连着问。
- **直觉模型「上车/下车」**：区间 [l, r] +v 就是「l 站上 v 人、r+1 站下 v 人」，任意时刻车上人数就是差分的前缀和——这个比喻能让你永远不写错端点。
- 边界三连问：`r + 1 == n` 越界不用减；题目给下标从 1 开始时先统一转成 0 基；还原时 `i == 0` 别读 `a[-1]`。
- 二维差分是二维前缀和的逆：子矩阵 `+v` 改 4 个角，还原则是二维前缀和——原理相同，考频低于一维，知道对称性即可。
