双指针（Two Pointers）里最经典的一支是**对撞指针**：在有序数组两端各放一个指针 `L`、`R`，
按当前「和」与目标的大小关系决定移动哪一端。枚举所有数对是 O(n²)，对撞指针每一轮**排除掉一批不可能的解**，
整体降到 O(n)。它和二分查找共享同一个前提——**有序性换比较次数**。

## Java 实现

```java
/** 有序数组中找和等于 target 的两个数的下标（LeetCode 167 题式输入） */
public static int[] twoSumSorted(int[] a, int target) {
    int l = 0, r = a.length - 1;
    while (l < r) {
        int sum = a[l] + a[r];
        if (sum == target) return new int[]{l, r};
        if (sum < target) l++;      // 和不够：R 左移只会更小，(l, l+1..r) 全部排除，只能 L 右移
        else             r--;      // 和超了：L 右移只会更大，(l..r-1, r) 全部排除，只能 R 左移
    }
    return new int[]{-1, -1};      // 指针相遇，无解
}
```

**正确性论证**（面试要能口述）：当 `a[l] + a[r] < target` 时，对区间内任意 `r' < r`，`a[l] + a[r']` 只会更小，
所以 `a[l]` 与任何一个候选配对都不可能等于 target——把 `l` 右移是安全的，**一次排除掉 r - l 个组合**。
反之亦然。两个指针各走不重复的一段路，总共 n - 1 步。

对照：**无序数组**的两数之和（LeetCode 1）不能这样做——没有序可用，标准解法是哈希表，
一遍扫描边查「target - a[i] 是否出现过」边存，O(n) 时间换 O(n) 空间。两种解法的取舍是高频考点：
有序给双指针（O(1) 空间），无序给哈希（O(n) 空间）。

## 复杂度与特点

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 时间 | O(n) | 每步 L 或 R 前进一格，最多 n - 1 步 |
| 空间 | O(1) | 两个下标 |
| 前提 | 数组有序 | 序提供「移动哪端」的判断依据 |
| 兄弟变体 | 快慢指针 / 同向指针 | 判环、去重、移除元素；滑动窗口是它的连续区间版 |

## 面试要点

- **三数之和（LeetCode 15）的套路**：排序 + 外层固定一个数 + 内层对撞指针找 `target - a[i]`，整体 O(n²)；去重的关键在外层跳过相同值、命中后 L、R 同时收缩并跳过重复。
- 其他对撞场景：**验证回文串**（跳过非字母数字后两端比较）、**盛最多水的容器**（短板端才可能让面积变大，移动短板）。
- 手写坑：循环条件是 `l < r` 而不是 `l <= r`（相遇时同一个元素不能配对自己）；题目若要求「两个不同元素」别把相等元素漏掉。
- 与滑动窗口的分界：对撞指针处理「两个独立位置」的配对关系，滑动窗口维护「一段连续区间」的聚合指标。
