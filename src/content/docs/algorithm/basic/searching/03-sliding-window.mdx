滑动窗口（Sliding Window）用**同向前进的两个指针 `L`、`R` 维护一段连续区间**：`R` 负责扩张吃进新元素，
`L` 负责收缩吐掉旧元素。适合「满足某约束的最长/最短连续子数组（子串）」这类问题。
它的高效根源是一条不变式：**每个元素至多被 R 吃进一次、被 L 吐出一次**，整体 2n 步，O(n)——
而暴力枚举所有连续区间是 O(n²) 起步。

## Java 实现

```java
/** 长度最小的子数组：和 ≥ target 的最短连续子数组长度（元素均为正数），不存在返回 0 */
public static int minSubArrayLen(int[] a, int target) {
    int n = a.length, best = n + 1;
    int l = 0, sum = 0;
    for (int r = 0; r < n; r++) {
        sum += a[r];                     // R 扩张：无条件吃进右端新元素
        while (sum >= target) {          // L 收缩：约束已满足，试着吐掉左端找更短
            best = Math.min(best, r - l + 1);
            sum -= a[l++];
        }
    }
    return best <= n ? best : 0;
}
```

模板的两个骨架就是演示里看到的动作：**外层 for 推 R（扩张），内层 while 推 L（收缩）**。
求「最长」时约束方向反过来——内层变成「不满足条件才收缩」，满足时更新答案，例如无重复字符的最长子串：

```java
public static int lengthOfLongestSubstring(String s) {
    int[] count = new int[128];              // 窗口内字符计数
    int best = 0, l = 0;
    for (int r = 0; r < s.length(); r++) {
        char c = s.charAt(r);
        count[c]++;
        while (count[c] > 1)                 // 窗口出现重复，从左端吐到不重为止
            count[s.charAt(l++)]--;
        best = Math.max(best, r - l + 1);
    }
    return best;
}
```

## 复杂度与特点

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 时间 | O(n) | L、R 各自单调前进，每元素至多进出窗口一次 |
| 空间 | O(1) 或 O(Σ) | 数值和用变量；字符/计数类需 O(字符集) 的计数表 |
| 前提 | 窗口指标随扩张/收缩**单调变化** | 正数数组的「和」满足：扩张必增、收缩必减 |
| 失效场景 | 含负数求和 | 单调性被破坏，应改用前缀和 + 有序集合/单调队列 |

## 面试要点

- **为什么正数是硬前提**：演示里「和不够 → 只能扩张」「和够 → 才收缩」依赖和的单调性；一旦有负数，吐掉左端可能让和变大，L 就不知道该不该动了。含负数的版本用「前缀和 + 单调递增队列」解。
- **判断一道题能否滑窗**，就问一句：「窗口指标（和/计数/不同元素数…）是否随扩张严格单调、随收缩严格反向？」是，套模板；否，换前缀和或二分答案。
- 收缩条件写 `while` 不是 `if`：满足约束后可能能连续吐掉多个左端元素（演示中窗口和 9 → 收缩两次才降到 7 以下）。
- 高频题型清单：最短覆盖子串（LC 76，计数窗口）、无重复最长子串（LC 3）、至多 K 个不同字符的最长子串、字符串排列包含判断（LC 438）。
