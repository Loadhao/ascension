经典题「荷兰国旗」：数组里只有三种值，**一次扫描**把它们分成「小于基准｜等于基准｜大于基准」三段连续区间。
它同时是快排的重要优化：普通两路分区在**大量重复元素**下会退化（所有相等元素都涌进一侧继续递归），
三路分区让相等的元素一次性全部归位、不再参与后续递归——这就是三路快排（Dijkstra 三向切分）。

## Java 实现

```java
/** 一次扫描三分：返回后 [lo, lt) < pivot，[lt, gt] == pivot，(gt, hi] > pivot */
public static void threeWayPartition(int[] a, int pivot) {
    int lt = 0, i = 0, gt = a.length - 1;
    while (i <= gt) {
        if (a[i] < pivot) {
            swap(a, lt++, i++);      // 换到「小于」段：换来的必然等于基准（来自中段），i 可以前进
        } else if (a[i] > pivot) {
            swap(a, i, gt--);        // 换到「大于」段：换来的是未知值，i 不动，下轮再检查
        } else {
            i++;                     // 等于基准：留在中段
        }
    }
}

/** 经典包装：颜色排序（LeetCode 75），0/1/2 就是以 1 为基准的三路分区 */
public void sortColors(int[] nums) {
    threeWayPartition(nums, 1);
}

private static void swap(int[] a, int i, int j) {
    int t = a[i]; a[i] = a[j]; a[j] = t;
}
```

为什么每个元素只被碰 O(1) 次：i 与 gt 只相向移动不回退，循环恰好执行 n 次，整体 O(n) 一趟、O(1) 空间。

## 复杂度与特点

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 时间 | **O(n)** 一趟 | i 每轮要么前进要么 gt 左移，总步数 ≤ 2n |
| 空间 | O(1) | 原地三指针 |
| 稳定性 | 不稳定 | 三段内部不保序（颜色排序无此需求） |
| 高频包装 | 颜色排序 LC75 / 快排优化 | 重复元素多时，快排应改三路版 |

## 面试要点

- **两路分区为什么怕重复**：Lomuto 分区里与基准相等的元素全落在「不小于」一侧，全是相等元素的数组每次分区只缩小 1，递归 O(n) 层退化成 O(n²)；三路分区把相等段整体挖掉，全部相等时一趟直接结束。
- **i 在不同分支动不动是手写最高频考点**：`<` 分支换来的元素来自「等于」段（已检查），i 前进；`>` 分支换来的元素来自未知区，i 原地不动再查一轮。
- 变体追问「只有两种值怎么分」：就是双指针版的 01 划分，一个指针扫、一个指针记边界，同样一趟。
- 与快排结合时，递归区间变成 `[low, lt-1]` 与 `[gt+1, high]`，中间等于段直接跳过——写三路快排时最容易漏的就是这两侧的新边界。
