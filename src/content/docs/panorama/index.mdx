:::note[图谱说明]
圆点大小 = 该方向/分类收录的知识点数量，底部图例即按数量降序的内容量排行。
首屏只标出各方向的名字，放大后分类名才逐级浮现，免得上百个标签糊成一片；
单击圆点聚焦放大、双击进入对应页面，悬停时左上角显示它所属的方向、等级与知识点数；
右上角搜索框输入关键词即时高亮匹配、回车定位到第一个，底部图例点按只看某个方向、点「全部」回到整体。
:::
