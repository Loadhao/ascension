全站知识以「方向 → 分类」两级收纳：每个彩色区块是一个学习方向，区块标注了它收录的
知识点数量，区块越大、其中的分类节点越大，代表内容越丰富。点击分类节点进入对应分类，
点击区块空白处进入该方向的学习路线。

<GlobalGraphIsland />

:::note[图谱说明]
区块与节点大小 = 收录的知识点数量，顶部图例按数量降序排列（即内容量排行）；悬停或点按
可高亮同方向内容，点按图例可只看某个方向，右上角按钮可缩放、复位视图。
:::
