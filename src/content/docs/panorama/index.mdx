全站知识图谱以「方向 → 分类」两级聚合：大节点是学习方向，围绕它的小节点是该方向的分类，
节点越大代表收录的知识点越多。点击任意节点进入对应的方向或分类。

<GlobalGraphIsland />

:::note[图谱说明]
节点大小 = 该方向/分类收录的知识点数量，图例按数量降序排列；悬停或点按节点高亮关联，
右上角按钮可缩放、复位视图，左下图例点按可只看某个方向。
:::
