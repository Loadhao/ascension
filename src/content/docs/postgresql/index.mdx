## 学习路线

按等级推进，每级下按主题分类。点击分类进入该主题的知识点目录；点击圆点标记学习状态：
○ 未学 → ◐ 学习中 → ● 已掌握。

当前覆盖**高可用与集群**（Pgpool-II 与 Postgres-XL 两种集群技术、pgpool
容灾高可用：流复制与主备自动切换）→ **性能优化**（连接池、索引与执行
计划、VACUUM 表膨胀、WAL 与 checkpoint 调参），后续可扩展 SQL 进阶、
备份恢复、逻辑复制等主题。
