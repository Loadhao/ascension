## 学习路线

点击圆点标记学习状态：○ 未学 → ◐ 学习中 → ● 已掌握。

当前覆盖**基础差异与 MVCC**（与 MySQL 的进程/复制/索引对照，以及
xmin/xmax、默认 RC、HOT、xid 回卷）→ **索引类型与 WAL**（GIN/GiST/BRIN
与 EXPLAIN 读法，物理 WAL / checkpoint / PITR）→ **高可用与集群**
（Pgpool-II 与 Postgres-XL、pgpool 容灾）→ **性能优化**（连接池、
VACUUM、checkpoint 调参）。
