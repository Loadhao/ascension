写 Python 和"工程化地写 Python"是两回事：依赖装在哪个环境、改完怎么
知道没改坏、风格和类型谁来把关、版本怎么发出去。现代答案是四件套——
uv 管"装"，pytest 管"对不对"，ruff + mypy 管"好不好"，
uv build/publish 管"发出去"。四者都是声明式配置
（pyproject.toml 单一事实源），CI 里串成一条质量流水线。
