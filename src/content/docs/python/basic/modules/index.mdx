写 Python 大多从单文件开始，长到几百行后第一件事就是**拆模块**：一个文件
一个模块，import 复用。这一分类讲清 import 的运行时语义（它决定了模块
单例、循环导入这些现象的根源）、包的组织方式与 API 门面，以及从"一堆
.py"到"规范项目"的布局演进。理解了这些，后面的工程化（uv、pytest、打包）
才不是死记命令。
