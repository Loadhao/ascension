Python 的语法重心和 Java 那套"变量是盒子"的心智模型完全不同：变量只是
**名字标签**，赋值是绑定而不是拷贝。先建立对象模型，后面所有内容——可变性、
哈希、闭包、装饰器——都建立在这之上。推导式是循环的语法糖，异常处理是
惯用控制流（EAFP），str/bytes 的编码边界是实战中最高频的坑。
