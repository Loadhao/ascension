Python 里函数是第一等公民：可以赋值、传参、返回。这一组笔记顺着一条线
展开——参数与作用域（可变默认值的坑）→ 闭包（捕获变量而非值）→ 迭代器
与生成器（惰性求值）→ 装饰器（闭包 + 语法糖 + 注册表模式）。装饰器是
FastAPI、pytest fixture 等框架的通用语言，值得吃透。
