标准库是 Python 的护城河：容器扩展（collections）、函数式工具
（functools/itertools）、现代文件路径（pathlib）、类型系统（typing）。
这一级的目标不是背 API，而是**在遇到问题时能想起"标准库里有现成的"**——
手写计数器之前先想想 Counter，手写目录遍历之前先看看 Path.glob。
