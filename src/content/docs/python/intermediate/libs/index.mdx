Python 生态的选型逻辑一条线：HTTP 客户端（requests 简单同步、httpx
同步异步通吃）→ 数据校验（Pydantic 把类型标注变成运行时护栏）→
Web 框架（FastAPI 把两者粘成声明式 API）。三者共同的特点是
**用类型标注声明"要什么"，框架负责"怎么拿"**。
