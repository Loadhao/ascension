## 学习路线

按等级推进，每级下按主题分类。点击分类进入该主题的知识点目录；点击圆点标记学习状态：
○ 未学 → ◐ 学习中 → ● 已掌握。

当前覆盖**核心机制**：ZooKeeper 的数据模型、ZAB 一致性协议与典型
应用场景，以及面试高频追问篇——ZAB 选举与广播细节、Watcher 一次性
触发的陷阱、Session 过期与"半死"状态。横向的共识算法（Paxos/Raft）
见「分布式」方向。
