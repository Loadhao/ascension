Spring Boot 不取代任何东西，它负责**装配**：自动配置把 Framework 与
MVC 拼成可运行程序，内嵌容器让它 java -jar 就跑，Actuator 让它可运维。

标记学习状态（未学 → 学习中 → 已掌握）。
