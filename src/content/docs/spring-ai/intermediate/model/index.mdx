**流式与非文本产出走哪条 API**。本分类把这些拆开讲：`ChatModel` 同时继承
`StreamingChatModel` 意味着什么、`ChatOptions` 那八个可移植旋钮之外的东西为什么不能指望
跨厂商一致、以及 2.0 把 Options 改成严格不可变之后"只改一项"该怎么写。
