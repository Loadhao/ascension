## 学习路线

点击圆点标记学习状态：○ 未学 → ◐ 学习中 → ● 已掌握。

当前覆盖三层：**基础 · 全景与调用门面**——Spring AI 的定位与依赖形态、2.0 断代清单、
`ChatClient` 流式 API 与结构化输出；**中级 · 上下文与工具**——Advisor 责任链与 `order`
语义、`ToolCallingAdvisor` 的位次、会话记忆的两层抽象与 2.0 的必填会话 ID、工具调用的三种
声明方式与执行归属；**高级 · 检索与协议**——`VectorStore` 与 ETL 管线、Naive 与 Modular
两档 RAG Advisor、MCP 客户端与服务端接入。

三种写法各管一段，别混：[AI 方向](/ai/basic/agent/01-agent-loop/)讲**原理**（Agent
Loop、RAG、记忆、工具这些本来要手写什么），[LangChain 方向](/langchain/basic/core/01-langchain-overview/)
讲 **Python 生态怎么落地**，本方向讲**Spring Boot 应用怎么落地**。跨方向的公共概念
在本方向只引不重复解释。
