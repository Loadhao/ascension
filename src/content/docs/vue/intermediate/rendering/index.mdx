响应式系统回答的是「改了数据谁会收到通知」，这一分类回答通知之后发生的事：一次
更新要跑哪些组件的渲染函数、虚拟 DOM 要比对多少节点、编译期又能替运行时省掉多

React 那样手工给组件套 memo。
