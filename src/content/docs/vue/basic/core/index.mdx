本分类是 Vue 3 的地基：**响应式系统**（Proxy 劫持与依赖收集，与
React 重渲染模式的对照）、**组件模型**（SFC 与单向数据流、v-model
的展开真相）、**Composition API**（按功能组织代码与逻辑复用），以及
**表单输入绑定**（同一个 `v-model` 在不同元素上接的到底是什么，值与
合格各由谁判）。点击右侧圆点可标记学习状态。
