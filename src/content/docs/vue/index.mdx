## 学习路线

点击圆点标记学习状态：○ 未学 → ◐ 学习中 → ● 已掌握。

当前覆盖**基础 · 核心概念**与**中级 · 渲染 / 状态 / 路由**三组：响应式系统的机制
真相、组件模型与单向数据流、Composition API 与逻辑复用、表单输入绑定，再往下是
更新粒度与列表身份（一次更新重做了什么、换了顺序凭什么认出同一行）、状态的归属与
派生（放哪一层、该存还是该算、变化之后做什么）、路由与导航控制。定位是后端工程师
的前端必备理解——响应式（推模式）与 React 的重渲染
（拉模式）对照着学最能建立完整心智模型（见 [React 方向](/react/)）。
