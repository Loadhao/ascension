TypeScript 不是「带类型的 JavaScript」这么简单，它是一层**只在开发期存在
的静态检查外壳**。这一篇从类型擦除讲起，把结构化类型、四个特殊类型与
类型收窄串成一条线——理解了「编译期之后类型就没了」，TS 的所有行为都能
推出来。点击右侧圆点可标记学习状态（未学 → 学习中 → 已掌握）。
