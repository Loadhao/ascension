## 学习路线

点击圆点标记学习状态：○ 未学 → ◐ 学习中 → ● 已掌握。

当前覆盖两层：**基础 · 核心概念**——控制平面架构与调谐循环、Pod
对象模型、Deployment 滚动发布、ConfigMap/Secret 配置注入；**中级 ·
运维要点**——探针三类分工与优雅退出、Service/Ingress 流量体系。
容器与镜像基础见「Docker」方向，两者是「单机容器 → 集群编排」的
递进关系。
