优雅退出）、**流量与发现**（Service 虚拟 IP、kube-proxy 转发、Ingress
七层入口），以及**控制面机制如何落到运维行为上**（List-Watch 调谐、
HPA 伸缩）。前置知识见[核心概念](/kubernetes/basic/core/)。
