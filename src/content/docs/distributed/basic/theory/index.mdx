所有分布式组件的设计分歧，最终都能追溯到两个根源问题：**网络分区时
保什么舍什么**（CAP 与 BASE），以及**数据怎么均衡地摊到 N 台机器上**
（一致性哈希）。这两篇是读懂 Nacos、Redis Cluster、Kafka、ZooKeeper
设计取舍的钥匙。点击右侧圆点可标记学习状态（未学 → 学习中 → 已掌握）。
