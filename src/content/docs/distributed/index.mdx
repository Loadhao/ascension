## 学习路线

按等级推进，每级下按主题分类。点击分类进入该主题的知识点目录；点击圆点标记学习状态：
○ 未学 → ◐ 学习中 → ● 已掌握。

当前覆盖 **理论基石**（CAP/BASE、一致性哈希、集群与分布式形态）与
**中级**（共识算法 Paxos/Raft/Gossip、分布式事务、分布式 ID、数据
分片、集群架构的负载均衡与会话、分布式协调的锁与幂等、服务治理的
RPC 原理、流量治理的分布式限流与超时重试、容量规划与压测、秒杀与
短链综合设计），并延伸出
**高级**工程化专题：数据一致性（含缓存双写、Quorum NWR、时钟与
顺序）、容灾多活、脑裂仲裁、发布策略与链路追踪。它们都是理解
Nacos、etcd、Redis Cluster、Seata、Kafka 背后设计取舍的通用语言，
也是面试高频区。
