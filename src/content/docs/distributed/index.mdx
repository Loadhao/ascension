## 学习路线

按等级推进，每级下按主题分类。点击分类进入该主题的知识点目录；点击圆点标记学习状态：
○ 未学 → ◐ 学习中 → ● 已掌握。

Paxos/Raft、分布式事务、分布式 ID）。它们是理解 Nacos、etcd、Redis
Cluster、Seata、Kafka 背后设计取舍的通用语言。
