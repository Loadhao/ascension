## 学习路线

点击圆点标记学习状态：○ 未学 → ◐ 学习中 → ● 已掌握。

当前覆盖两层：**基础 · 注入类攻击**——XSS、CSRF、SQL 注入的原理
与防御主战场；**中级 · 认证授权攻防**——会话安全、越权与 RBAC、
开放 API 签名与防重放。机制概念（Cookie/Session/JWT、HTTPS、密码
哈希、CORS）见「网络」方向的 [HTTP 系列](/network/basic/http/01-http-basics/)，
本方向站在它之上专讲攻防。
