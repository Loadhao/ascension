本分类攻防入门三板斧：**XSS 让输入变代码、CSRF 借浏览器自动带
Cookie 发伪造请求、SQL 注入让数据参与语法**。三者防御指向一致的
工程纪律——转义在输出口、token 校验在服务端、参数化在数据层。
