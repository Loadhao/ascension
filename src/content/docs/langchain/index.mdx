## 学习路线

点击圆点标记学习状态：○ 未学 → ◐ 学习中 → ● 已掌握。

当前覆盖两层：**基础 · 核心抽象**——统一模型接口、prompt 模板与
结构化输出、LCEL 组合协议；**中级 · LangGraph 编排**——状态图

多 Agent 范式）见「AI」方向，两边互相引用。
